## 1. FindLargest Procedure

Create a procedure named FindLargest that receives two parameters: a pointer to a signed doubleword array, and a count of the array’s length. The procedure must return the value of the largest array member in EAX. Use the PROC directive with a parameter list when declaring the procedure. Preserve all registers (except EAX) that are modified by the procedure.

Write a test program that calls FindLargest and passes three different arrays of different lengths. Be sure to include negative values in your arrays. Create a PROTO declaration for FindLargest.
```
정답
INCLUDE Irvine32.inc

FindLargest PROTO,
    pArray:PTR SDWORD,
    arrayCount:DWORD

.data
array1 SDWORD 10, -5, 30, 20
array2 SDWORD -10, -3, -20, -1, -15
array3 SDWORD 100, 200, -50

resultMsg BYTE "Largest value: ", 0

.code
main PROC

    INVOKE FindLargest, ADDR array1, LENGTHOF array1
    call DisplayResult

    INVOKE FindLargest, ADDR array2, LENGTHOF array2
    call DisplayResult

    INVOKE FindLargest, ADDR array3, LENGTHOF array3
    call DisplayResult

    exit
main ENDP

FindLargest PROC USES esi ecx,
    pArray:PTR SDWORD,
    arrayCount:DWORD

    mov esi, pArray
    mov ecx, arrayCount

    mov eax, [esi]
    add esi, 4
    dec ecx

L1:
    cmp ecx, 0
    je Done

    cmp SDWORD PTR [esi], eax
    jle Next

    mov eax, [esi]

Next:
    add esi, 4
    loop L1

Done:
    ret

FindLargest ENDP

DisplayResult PROC
    mov edx, OFFSET resultMsg
    call WriteString

    call WriteInt
    call Crlf

    ret
DisplayResult ENDP

END main
```

## 2. Chess Board

Write a program that draws an 8 × 8 chess board, with alternating gray and white squares. You can use the SetTextColor and Gotoxy procedures from the Irvine32 library. Avoid the use of global variables, and use declared parameters in all procedures. Use short procedures that are focused on a single task.
```
정답
INCLUDE Irvine32.inc

DrawSquare PROTO, row:DWORD, col:DWORD, color:DWORD
DrawBoard PROTO

.data
.code

main PROC
    INVOKE DrawBoard
    call WaitMsg
    exit
main ENDP

DrawBoard PROC USES eax ecx edx,
    LOCAL row:DWORD,
    LOCAL col:DWORD

    mov row, 0

RowLoop:
    cmp row, 8
    jge BoardDone

    mov col, 0

ColLoop:
    cmp col, 8
    jge NextRow

    mov eax, row
    add eax, col
    and eax, 1

    cmp eax, 0
    jne Gray

    INVOKE DrawSquare, row, col, lightGray
    jmp ContinueCol

Gray:
    INVOKE DrawSquare, row, col, white

ContinueCol:
    inc col
    jmp ColLoop

NextRow:
    inc row
    jmp RowLoop

BoardDone:
    ret

DrawBoard ENDP

DrawSquare PROC USES eax ebx edx,
    row:DWORD,
    col:DWORD,
    color:DWORD

    mov eax, color
    call SetTextColor

    mov eax, col
    shl eax, 1
    inc eax

    mov ebx, row
    inc ebx

    call Gotoxy

    mov al, ' '
    call WriteChar
    call WriteChar

    ret

DrawSquare ENDP

END main
```

## 4. FindThrees Procedure

Create a procedure named FindThrees that returns 1 if an array has three consecutive values of 3 somewhere in the array. Otherwise, return 0. The procedure’s input parameter list contains a pointer to the array and the array’s size. Use the PROC directive with a parameter list when declaring the procedure. Preserve all registers (except EAX) that are modified by the procedure.

Write a test program that calls FindThrees several times with different arrays.
```
정답
INCLUDE Irvine32.inc

FindThrees PROTO,
    pArray:PTR SDWORD,
    arrayCount:DWORD

.data
array1 SDWORD 1, 3, 3, 3, 5
array2 SDWORD 3, 3, 2, 3, 3
array3 SDWORD 1, 2, 3, 4, 5

.code
main PROC

    INVOKE FindThrees, ADDR array1, LENGTHOF array1
    call WriteDec
    call Crlf

    INVOKE FindThrees, ADDR array2, LENGTHOF array2
    call WriteDec
    call Crlf

    INVOKE FindThrees, ADDR array3, LENGTHOF array3
    call WriteDec
    call Crlf

    exit
main ENDP

FindThrees PROC USES esi ecx,
    pArray:PTR SDWORD,
    arrayCount:DWORD

    mov esi, pArray
    mov ecx, arrayCount

    cmp ecx, 3
    jb NotFound

    sub ecx, 2

L1:
    cmp DWORD PTR [esi], 3
    jne Next

    cmp DWORD PTR [esi+4], 3
    jne Next

    cmp DWORD PTR [esi+8], 3
    je Found

Next:
    add esi, 4
    loop L1

NotFound:
    mov eax, 0
    ret

Found:
    mov eax, 1
    ret

FindThrees ENDP

END main
```

## 9. Counting Nearly Matching Elements

For each element xᵢ in the first array, if the difference between it and the corresponding yᵢ in the second array is less than or equal to diff, increment a count. At the end, return a count of the number of nearly matching array elements in EAX. Write a test program that calls CountNearMatches and passes pointers to two different arrays of integers.
