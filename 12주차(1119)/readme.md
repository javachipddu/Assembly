# 어셈블리프로그래밍 12주차 수업(1119)

## 10. 구조체와 매크로

구조체: 논리적으로 관련이 있는 변수들의 그룹

클래스=구조체+함수

구조체(Struct): 각 멤버가 서로 다른 메모리 공간을 사용한다.

공용체(Union): 모든 멤버가 동일한 메모리 공간을 공유한다.

Direct와 Indirect의 차이

Direct(직접 주소 지정): 데이터가 저장된 메모리 주소를 직접 지정

Indirect(간접 주소 지정): 데이터가 저장된 메모리 주소를 가리키는 다른 주소나 레지스터를 이용
