## 10. 구조체와 매크로

구조체: 논리적으로 관련이 있는 변수들의 그룹

클래스=구조체+함수

구조체(Struct): 각 멤버가 서로 다른 메모리 공간을 사용한다.

공용체(Union): 모든 멤버가 동일한 메모리 공간을 공유한다.
