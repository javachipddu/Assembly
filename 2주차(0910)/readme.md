## CPU

 ### 1\. ALU(Arithmetic Logic Unit, 산술논리연산장치)

 CPU에서 **산술 연산과 논리 연산을 수행하는 회로**이다.

 #### 주요 기능

 ALU는 크게 두 종류의 연산을 수행한다.

 - **산술 연산(Arithmetic)**
  - 덧셈: `A + B`
  - 뺄셈: `A - B`
  - 증가: `A + 1`
  - 감소: `A - 1`
  - 경우에 따라 곱셈/나눗셈도 별도의 연산 유닛에서 수행
- **논리 연산(Logic)**
  - AND: `A & B`
  - OR: `A | B`
  - XOR: `A ^ B`
  - NOT: `~A`
  - 비교 연산 등

 예를 들어,

```
A = 0101 (5)
B = 0011 (3)

A + B
  ↓
ALU
  ↓
1000 (8)
```

 ALU가 실제로 `5 + 3 = 8`이라는 계산을 수행한다.

 ### 2\. CU (Control Unit, 제어 장치)

 **CU는 프로세서 내부에서 명령어의 실행을 제어하는 장치**이다.

 CPU가 명령어를 처리할 때,

 > “무슨 명령어인가?” → “어떤 동작을 해야 하는가?” → “어떤 회로를 언제 동작시킬 것인가?”

 를 결정하고 각 구성 요소에 \*\*Control Signal(제어 신호)\*\*을 전달합니다.

 예를 들어 CPU가 `ADD R1, R2`를 실행한다면 CU는 대략적으로:

 - 명령어를 Decode
- R1, R2의 값을 읽도록 제어
- ALU가 덧셈을 수행하도록 제어
- 결과를 목적 레지스터에 저장하도록 제어

 하는 역할을 한다.

 **CU = CPU의 동작을 지시하고 조정하는 제어 장치**

 라고 이해하면 된다.

 ### 3\. Clock (클럭)

 **Clock은 디지털 회로의 동작 타이밍을 맞추기 위해 주기적으로 반복되는 전기적 신호**이다.

 일반적으로 다음과 같은 파형을 사용한다.

```
       ┌───┐     ┌───┐     ┌───┐
       │   │     │   │     │   │
───────┘   └─────┘   └─────┘   └───
       ↑         ↑         ↑
     Clock     Clock     Clock
      Edge      Edge      Edge
```

 Clock의 한 주기가 지나갈 때마다 레지스터, 플립플롭 등의 순차회로가 정해진 시점에 데이터를 저장하거나 상태를 변경한다.

 예를 들어 **1 GHz Clock**이라면 이상적으로 1초에 10억 번의 주기가 발생하며,

 $$
T = \frac{1}{f} = \frac{1}{1GHz} = 1ns
$$

 이므로 Clock Period는 **1 ns**이다.
