| 레지스터   | 이름          | 전통적인 주요 용도             |
| ------ | ----------- | ---------------------- |
| **AX** | Accumulator | 산술/논리 연산, 함수 반환값 등     |
| **BX** | Base        | 주소 계산의 기준값             |
| **CX** | Counter     | 반복문, shift/rotate 횟수 등 |
| **DX** | Data        | 산술 연산의 보조 데이터, I/O 등   |
