# 어셈블리프로그래밍 6주차 수업(1015)

정수형: short, int, long, long long (signed가 생략되어 있음)

실수형: float, double

문자형: char (8비트 / -128~127)

(unsigned char는 0~255)

논리형: _Bool (C99부터 지원)

값이 없음을 나타내는 타입: void

부호 없는 정수형: unsigned int (무조건 0부터 처리)
